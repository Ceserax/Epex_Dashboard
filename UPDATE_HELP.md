# Requirements for Epex Dashboard

This document outlines the packages required to run the Epex Dashboard successfully.

## Required Packages:

1. Flask==2.2.2
2. requests==2.26.0
3. pandas==1.3.3
4. numpy==1.21.2
5. matplotlib==3.4.3
6. SQLAlchemy==1.4.25

Ensure that all packages are installed in your Python environment to avoid runtime errors.
